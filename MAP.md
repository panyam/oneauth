2. [`grpc/`](grpc/doc.go) · [diagrams](grpc/diagrams.md) — Authentication context utilities and server interceptors for propagating the authenticated user ID across the HTTP-to-gRPC boundary via gRPC metadata, with optional auth enforcement and switch-user impersonation.
3. [`oauth2/`](oauth2/doc.go) · [diagrams](oauth2/diagrams.md) — Self-contained OAuth2 social-login providers (Google, GitHub) with a shared base, PKCE support, and state-cookie CSRF protection, delivering the authenticated user to a host-supplied HandleUserFunc.
4. [`saml/`](saml/doc.go) · [diagrams](saml/diagrams.md) — POC SAML 2.0 SP integration wrapping crewjam/saml behind redirect-style login/logout/ACS handlers that hand off authenticated users via an OAuth2-token-shaped callback.
5. [`utils/`](utils/doc.go) — Crypto and encoding helpers — PEM/PKCS8 key gen and parsing, JWK/JWKS conversion, RFC 7638 kid thumbprints, JWT signing-method lookup, and Flask session-cookie decoding.
6. [`client/`](client/doc.go) · [diagrams](client/diagrams.md) — Client-side OAuth SDK for oneauth — AS discovery, browser/PKCE login, client-credentials and private_key_jwt token acquisition with caching/refresh, dynamic client registration, and an auth-injecting HTTP transport.
7. [`httpauth/`](httpauth/doc.go) · [diagrams](httpauth/diagrams.md) — Session-based HTTP auth glue plus standalone middleware for CSRF, security headers, and request body limits.
8. [`keys/`](keys/doc.go) · [diagrams](keys/diagrams.md) — Owns signing-key storage, lookup, encryption-at-rest, kid-based rotation with grace periods, and JWKS publication/consumption for OneAuth.
9. [`localauth/`](localauth/doc.go) · [diagrams](localauth/diagrams.md) — HTTP handlers and store-backed callbacks for local username/password authentication — signup, login, email verification, password reset, and credential linking onto OAuth users.
10. [`admin/`](admin/doc.go) · [diagrams](admin/diagrams.md) — Owns OneAuth's client-administration surface — RFC 7591 DCR, RFC 7592 management, the proprietary /apps registry, admin CRUD, key rotation with grace periods, and resource-token minting — behind gRPC-shaped interfaces with thin HTTP wrappers.
11. [`apiauth/`](apiauth/doc.go) · [diagrams](apiauth/diagrams.md) — Transport-independent OAuth 2.0 core (token issuance, validation, introspection, revocation, client authentication) plus thin HTTP bindings for the token endpoint, RFC 7662/7009 handlers, AS/PRM metadata, and resource-server middleware.
12. [`client/stores/fs/`](client/stores/fs/doc.go) — A filesystem-backed credential store that persists oneauth client server credentials as a single JSON file keyed by normalized server URL.
13. [`keystoretest/`](keystoretest/doc.go) — Shared contract test suite that every KeyStore backend (inmem, gorm, fs, gae) runs against its own factory.
14. [`kidstoretest/`](kidstoretest/doc.go) — Shared, test-only contract suite that every KidStorage backend (in-memory KidStore, FS, GORM, GAE) runs against its own factory, mirroring keystoretest.
15. [`stores/gae/`](stores/gae/doc.go) · [diagrams](stores/gae/diagrams.md) — Google Cloud Datastore-backed implementations of oneauth's KeyStorage, KidStorage, and the core user/identity/channel/token/API-key/username store interfaces, with namespace-based multi-tenancy.
16. [`appstoretest/`](appstoretest/doc.go) — Shared contract test suite that every AppRegistrationStore backend (inmem, fs, gorm) runs against its own factory to prove uniform behavior.
17. [`stores/fs/`](stores/fs/doc.go) — Filesystem-backed (JSON-file-per-record) implementations of OneAuth's KeyStore, KidStore, AppRegistrationStore, User/Username/Identity/Channel/Token/RefreshToken/APIKey store interfaces, intended for single-process dev and small deployments.
18. [`stores/gorm/`](stores/gorm/doc.go) · [diagrams](stores/gorm/diagrams.md) — GORM/SQL-backed implementations of every oneauth store interface (users, identities, channels, tokens, refresh tokens, API keys, usernames, signing keys, kid keys, app registrations) plus AutoMigrate, usable on any GORM driver.
19. [`testutil/`](testutil/doc.go) — Reusable in-process authorization server and standalone OAuth/JWT test helpers for oneauth and downstream integration tests.
