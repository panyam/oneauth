Why a site, not just the README?

OneAuth's conformance posture is a public contract: "OneAuth substitutes for X on these specs, with this measured pass rate." A stable URL with navigation beats grepping through gitignored test-reports/ for the answer. The source-of-truth files still live in the repository (the OIDF scorecard at tests/oidf-conformance/SCORECARD.md is auto-regenerated by make testoidf; the per-IdP interop docs live under docs/conformance/); this site just renders them with consistent navigation.
