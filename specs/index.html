OAuth and OIDC spec library

Per-RFC summaries: what each spec does, why it exists, and exactly where OneAuth stands on it.

One page per specification. Each summarises what the spec is for, when to reach for it, and carries a grep-verified table of where OneAuth stands on every surface it defines. These are written for deciding what to build next, not as a replacement for the RFC text.
